Detailed Description

Test for UploadSrvPage::check_by_whitelist() @runTestsInSeparateProcesses @preserveGlobalState disabled.

Regression coverage for: the "Upload from Server" whitelist must never fail open. Before the fix, an empty entry (empty setting, trailing or doubled ":") matched every path, and entries were compared as plain string prefixes ("/tmp" also allowed "/tmpevil/x").
