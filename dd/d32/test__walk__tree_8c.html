Detailed Description

Nested-set parity and per-node heartbeat regression tests.

Exercise the production traversal without a database or scheduler process. Database updates are captured as (uploadtree_pk, lft, rgt) tuples; heartbeat calls are checked and forwarded to the real scheduler library. This tests progress/aliveness updates, not wall-clock heartbeat delivery or DB latency.
