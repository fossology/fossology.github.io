Detailed Description

Import source for CycloneDX JSON SBOMs (specVersion 1.4 and later).

Only licenses explicitly marked with "acknowledgement": "concluded" are treated as concluded licenses. Every other license (declared, unmarked or from the evidence block) is imported as a license info in file.
